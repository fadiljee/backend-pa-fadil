# reference/ — Gambar Acuan

Simpan screenshot referensi di sini, **dipotong per section**, resolusi setinggi mungkin (idealnya lebar ≥ 1440px). Gunakan nama persis ini agar `sections.md` dapat menunjuknya:

| File | Isi |
|---|---|
| `00-fullpage.png` | Seluruh halaman |
| `01-navbar-hero.png` | Navbar |
| `02-hero-carousel.png` | Carousel foto + dot |
| `03-welcome.png` | Judul welcome + tombol |
| `04-stats.png` | Band statistik merah |
| `05-mosaic.png` | Mosaik foto |
| `06-news.png` | News & Events |
| `07-calendar-cta.png` | Banner kalender |
| `08-announcements.png` | Daftar pengumuman |
| `09-footer.png` | Footer |
| `mobile/*.png` | (opsional) referensi tampilan mobile per section |

Tips: jika ada file Figma/Dribbble asli, ekspor per frame. Catat font, warna, dan ukuran yang terbaca langsung dari file asli bila memungkinkan, lalu perbarui `design.md`.
